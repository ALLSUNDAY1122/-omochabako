# おもちゃばこ

花束・子どもの作品・記念品を、やさしい操作で立体的な思い出として残すiPhone向けアプリの価値検証用Web試作です。

## 現在の範囲

- カテゴリ選択
- 撮影準備チェック
- カメラ撮影導線
- 撮影不足の簡易警告
- 3D生成進捗の仮表示
- 仮3Dプレビュー
- 思い出情報入力
- 撮影元データを残す／削除する選択
- ブラウザ内保存

実際の3D再構築エンジンは未実装です。

## GitHub Pages公開

1. GitHubのリポジトリで `Settings` を開く
2. 左メニューの `Pages` を開く
3. `Build and deployment` の `Source` を `Deploy from a branch` にする
4. Branchを `main`、フォルダーを `/(root)` にする
5. `Save` を押す
